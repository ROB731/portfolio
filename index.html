Qui suis-je ?

Concepteur-développeur full-stack basé à Abidjan, Marcory. Je pars du besoin de l'entreprise, je le conçois, je l'installe et je forme les utilisateurs : applications web et mobiles, PWA, API REST, automatisations et agents IA.
